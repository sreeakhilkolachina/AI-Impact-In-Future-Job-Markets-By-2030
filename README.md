# AI-Impact-in-Future-Job-Markets-by-2030
Workforce Analytics Dashboard

Overview of the Project:

Created an interactive dashboard using Microsoft Power BI platform / tool. The dashboard is prepared for the analysis, comparisons and identifying the trends of AI Impact on Job Market from 2026 – 2030. Which is titled as AI Impact in Future Job Markets By 2030. The DAX (Data Analysis Expressions) are used in this project to create calculated measures and calculated column. The dataset used here is in CSV (Comma - Separated Values) format. Which is sourced from Kaggle (Public Dataset). The project consist of three interactive dashboards / sheets.Dashboard / Sheet – 1: Title Page. Dashboard / Sheet – 2: Overall Overview. Dashboard / Sheet – 3: AI Impact Analysis.
